## Getting started

1. Register and sign in to EasyAI.
2. Subscribe, then connect ChatGPT, Claude, or an OpenAI API key, or request an additional paid EasyAI-managed account.
3. Install EasyAI on the development computer, enter the one-time pairing code, and choose the project directory it may access.
4. In the workspace, choose a project, online computer, model account, and model before sending a task.
5. Approve file writes, commands, and Git operations before they run on the development computer.
6. Keep the development computer online to continue the same session from a phone, browser, or another computer.

EasyAI does not host complete source repositories by default. Your repositories remain on your computer or your own Git remote.
